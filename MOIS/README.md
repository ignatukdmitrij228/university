## Лабы

- [LABA2](./LABA2) - Нахождение эйлеровых и гамильтоновых циклов в неориентированном графе.
- [LABA3](./LABA3) - Нахождение кратчайшего пути в графе.
- [LABA4](./LABA4) - Нахождение минимального остового дерева неориентированного графа.
- [LABA5](./LABA5) - Определение компонент сильной связности в орграфе. Определение компонент двусвязности для неориентированного графа.
- [LABA6](./LABA6) - Проверка бинарных деревьев на изоморфность.
- [LABA7](./LABA7) - Группы. Некоторые свойства перестановок (подстановок).
